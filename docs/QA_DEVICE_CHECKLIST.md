# 実機での確認チェックリスト(PR D)

自動テスト(Playwright の Pixel 7 相当の Chromium・デスクトップ Chrome、axe-core)で確かめられない項目。
**`DEVICE_MANUAL_QA=UNEXECUTED`**(物理端末を操作していない)。確認したら日付・端末・OS・ブラウザの版・結果を下の表に記録する。

- 実在のレシート・口座・個人情報を画面に出したままスクリーンショット・動画を撮らない(撮る場合は架空のデータで)。
- 確認用のデータは、テスト用のグループ・架空の名前・架空の口座で作る。

## 項目
1. 起動・表示
   - [ ] 縦向き・横向きで、画面下のボタンがキーボード・ホームバーに隠れない
   - [ ] 文字サイズを最大にしても、金額・ボタンが切れない
   - [ ] ダークモードの端末でも文字が読める(画面は明るい配色で固定)
2. 支出の入力
   - [ ] 金額の入力で数字キーボードが出る。全角・カンマ付きでも正しく入る
   - [ ] 日付の入力欄が枠からはみ出さない(iOS Safari)
   - [ ] 「この内容で登録」を素早く 2 回押しても 1 件だけ登録される
3. レシートの撮影(OCR を有効にした環境)
   - [ ] カメラが起動し、撮った画像が送られる。位置情報が残らない(サーバーで EXIF を消す)
   - [ ] 読み取り中に画面を閉じても、戻ると結果が出る
   - [ ] 「要確認」の理由が日本語で表示される
4. 精算・送金の記録
   - [ ] 金額・口座番号のコピーができ、貼り付けた内容が正しい(https で開いたとき)
   - [ ] 振込先を表示した後、別のアプリから戻る・別の送金へ移る・ログアウトすると、前の口座が残らない
5. 通信
   - [ ] 機内モードで登録すると「通信に失敗しました…」と出て、戻すと 1 件だけ登録できる
   - [ ] 戻る・進む(スワイプ)で二重に登録されない
6. 読み上げ(VoiceOver / TalkBack)
   - [ ] 画面名・ボタン・金額・状態(未送金・送金の申告あり)が読み上げられる
   - [ ] 確認ダイアログ・下から出るシートで、後ろの画面の要素に移動しない
   - [ ] エラーが読み上げられる(role=alert)
