# WariLink プライバシーポリシー(下書き・未確定)

> **確定したプライバシーポリシーではありません。** 公開前に運営者と専門家の確認が必要です(`OWNER_APPROVAL_REQUIRED`)。
> 日数は `apps/api/app/core/config.py` の既定値と `docs/DATA_MODEL.md` §11 の方針(2026-10-28 決定)です。導入先で変えた場合は合わせて直します。

## 1. 取り扱う者・問い合わせ先
`OWNER_APPROVAL_REQUIRED`(個人データの取り扱いの責任者、問い合わせ窓口)

## 2. 取得する情報と目的
| 情報 | 目的 |
|---|---|
| グループ名・メンバーの表示名・支出(内容・金額・日付・カテゴリ)・精算の記録 | 割り勘と精算の計算・表示 |
| レシートの画像と読み取った文字 | 支出の下書きの作成(位置情報などの EXIF は保存しません) |
| 振込先(登録した人だけ。暗号化して保存) | その送金の支払う人への表示 |
| Passkey の公開鍵(登録した人だけ) | ログイン・本人の再確認 |
| ログインの記録(Cookie `wl_session`、有効期限 最長 90 日) | 利用者の識別 |
| 操作の記録(監査ログ。ID と件数だけで、口座・名前は書きません) | 不正利用の調査 |
| 接続元 IP の鍵付きハッシュ(一定時間で削除) | 大量の要求の制限(元の IP は保存しません) |

- メールアドレス・電話番号は取得しません。
- この端末にだけ保存するもの(サーバーに送りません): 既定の表示名、作成者が発行した招待リンク(ブラウザの localStorage)。
- 利用者のデータを、広告・購買分析・外部への販売・OCR の学習に使いません。これらに使う場合は、目的ごとの任意の同意を得てからにします(同意の仕組みは未実装)。

## 3. 保存期間
| 情報 | 期間 |
|---|---|
| レシートの画像と読み取った文字 | アップロードから 30 日(支出として登録した商品・金額は残ります) |
| 操作の記録 | 1 年 |
| 失効・期限切れのログインの記録・招待 | 30 日 |
| 参加者がいなくなったグループ | 最後の参加者が抜けてから 30 日ですべて削除 |
| 終了したグループ | 終了から 1 年ですべて削除 |
| バックアップ | 30 日 |

- 期間を過ぎたデータを消す処理は、1 日 1 回の定期ジョブです。**導入先でジョブを登録していない場合は、期間を過ぎても消えません。**
  画面(データの保存期間)は、処理が直近で動いたことを確認できたときだけ「動いています」と表示します。

## 4. 退会と削除
- 退会すると、ログインの記録と Passkey は使えなくなり、振込先は元に戻せない形で消去します(伏せ字の表示だけ残ります)。
- 参加していたグループには、ほかのメンバーとの記録として、名前と支出・精算の記録が残ります(グループが削除されるまで)。
- 削除する前に取ったバックアップには、最長 30 日残ります。バックアップから戻した場合も、削除済みの一覧で削除を再び適用します。
- データベースの外の複製(WAL・スナップショット・バックアップの保管先の複製)の扱いは、保管先が決まってから定めます(`OWNER_APPROVAL_REQUIRED`)。
  **現時点では、それらを含めた完全な削除は保証できません。**
- 開示・訂正・利用停止の求めへの対応: `OWNER_APPROVAL_REQUIRED`

## 5. 第三者への提供・外部サービス
- 法令に基づく場合を除き、第三者に提供しません: `OWNER_APPROVAL_REQUIRED`(文言の確認)
- 利用する外部サービス(ホスティング・保管先など)と、海外に保存するかどうか: `OWNER_APPROVAL_REQUIRED`
- レシートの読み取りは自前のサーバーで行い、外部の OCR サービスには送りません(現行の実装)。

## 6. 安全管理
- 振込先は暗号化して保存し、表示できるのはその送金の支払う人だけです。鍵の管理サービス(KMS)への移行は未実施です。
- バックアップの暗号化・外部保管は準備中です(PR C)。
